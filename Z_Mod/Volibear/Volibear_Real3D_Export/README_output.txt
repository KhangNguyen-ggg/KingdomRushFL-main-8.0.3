ORIGINAL 3D VOLIBEAR ANIMATION RENDER
====================================
frames/ = individual transparent PNG frames (fixed camera and canvas).
atlases/ = PNG sprite sheets + matching .lua atlas metadata for KR FL.
volibear_animation_map.lua = playback timing, including repeated frames.
Important: these are character-only model frames, not full League VFX.
The hero code still must register all go_volibear_* texture groups.
Do not paste unintegrated files into the game and expect instant compatibility.
